## 已真实通过：微博一键扫码登录

客户侧流程已经真实可用：

```text
启动软件
→ 账号管理
→ 扫码登录微博
→ 手机微博 APP 扫码确认
→ 程序自动保存登录状态和发布凭据
→ 软件自动显示“已登录”
```

- [x] Windows 本机真实扫码成功。
- [x] 不需要命令行。
- [x] 不需要手动复制 Cookie。
- [x] 不需要额外点击“检测状态”才能完成登录。
- [x] 登录依据使用当前 Profile 中真实微博 Cookie，不再依赖固定页面 DOM。

- [ ] 关闭并重启 autoSendManhua，确认登录状态仍可直接复用。

## 微博“发布成功 → 正确详情链接”实现

当前识别顺序：

```text
1. 发布接口响应
   ↓
2. 本人主页移动端 API 前后差分
   ↓
3. 桌面微博主页 DOM 前后差分
```

候选必须满足：

- [x] 属于当前登录 UID（能取得 UID 时）。
- [x] 是本次发布后的新增微博。
- [x] 发布时间在本次提交附近。
- [x] 图片数量一致。
- [x] 正文指纹一致。
- [x] 只能唯一匹配一条；多个候选时不猜。
- [x] 无法唯一确认时进入 `PublishUncertainError`，禁止自动重发。
