## 复现命令

在项目目录运行：

```powershell
node scripts/audit-core.mjs
node scripts/audit-ui.mjs
```

两个脚本按正确行为断言，目前退出码为 1，表示仍有不满足项。
修复后应逐条由失败转为通过，而不是删除断言或把错误结果定义为成功。
原有 npm test 的 Electron smoke 会启动应用并执行恢复逻辑；应通过 AUTO_SEND_MANHUA_ROOT 指向独立测试目录运行。

## 尚可确认的成果

- 仓库、依赖、SQLite 建表、任务/job 存储、模板替换、xlsx 逐行校验和结果导出代码已存在。
- Electron 的七个导航区能打开；preload API 可用。
- 简单模拟场景下，微博失败阻断下游；一个发布器抛错后另一个平台可继续；正常落库的 success job 不重复执行。
- 以上结论均有适用范围，不包含提交后故障、并发、真实网站发布及审核流程。

产品开发目标仍未完成。本次完成的是审计，不是产品修复或真实发布验收。
