# autoSendManhua

面向漫画/资源内容的多平台分发工具。

## 核心发布链路

```text
标题 + 正文 + 图片 + 资源链接（百度网盘 / 夸克 / 迅雷等）
                    ↓
                 先发微博
                    ↓
           获取刚发布微博的详情/分享链接
                    ↓
      将微博分享链接写入各平台发布模板
                    ↓
   知乎 / 简书 / 百家号 / 今日头条 / 其他平台
```

## 设计原则

1. 微博是前置依赖：只有微博发布成功并拿到微博链接后，后续平台任务才开始。
2. 各平台独立适配：一个平台失败不影响其他平台，可单独重试。
3. 登录态持久化：每个平台使用独立浏览器 Profile 保存登录状态。
4. 发布结果可追踪：记录原始资源链接、微博链接、各平台发布 URL、状态和错误原因。
5. 旧项目 `autoPushWeibo` 保持独立，本仓库不会直接修改它。
